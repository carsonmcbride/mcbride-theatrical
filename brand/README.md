# McBride Theatrical Consulting — logo files

## The mark

A beam of light and the pool it lands in. Two shapes, no font, no gradient — which is why
it survives being printed at 14px in a drawing title block.

## Which file to use

| Situation | File |
|---|---|
| Website, dark backgrounds | `mcbride-logo-horizontal.svg` |
| Letterhead, invoices, anything on white | `mcbride-logo-horizontal-black.svg` |
| Drawing title blocks, faxes, single-colour print | `mcbride-logo-horizontal-black.svg` |
| Narrow or square spaces | `mcbride-logo-stacked*.svg` |
| Reversed out of a photo or dark panel | `*-white.svg` |
| Avatar, favicon, app icon, shirt | `mcbride-mark-*.svg` |
| Browser tab | `mcbride-favicon.svg` |

Rule of thumb: use the full lockup wherever there's room, the mark alone only where the
name already appears nearby or space is square.

## Colours

| | Hex | Use |
|---|---|---|
| Amber | `#f2a63b` | The mark, on dark backgrounds |
| Near-black | `#08080a` | Backgrounds, and the whole logo on white |
| Cream | `#ece9e4` | Wordmark on dark |
| Warm grey | `#a5a19b` | "Theatrical Consulting" line on dark |

Single-colour reproduction (embroidery, engraving, one-colour print) uses solid black or
solid white. Don't put amber on white — it goes muddy and loses contrast.

## Type

Wordmark: **Playfair Display** Semibold. Subtitle: **Inter** Medium, letterspaced.
Both are free from Google Fonts and already loaded by the website.

## One thing to do before printing

The `<text>` in the lockup files is live text, not outlines. Browsers render it correctly,
but a print shop's software may substitute a different font if Playfair Display isn't
installed on their machine.

Any printer or sign shop can fix this in ten seconds — ask them to **convert text to
outlines** (Illustrator: select all → Type → Create Outlines). It's a routine request and
they'll usually ask for it anyway. The mark files contain no text and need nothing done
to them.

## Clear space and minimum size

Leave clear space around the logo equal to the height of the mark. Don't go below about
100px wide for the horizontal lockup on screen, or 1 inch in print — below that, use the
mark on its own.

## Don't

- Recolour it outside the palette above
- Stretch it — scale proportionally only
- Add a drop shadow, glow, or outline
- Rebuild the lockup by hand; use the supplied files so spacing stays consistent
- Place the amber version on a light background
